Honest limits

All frames in this build are procedurally generated demonstration frames, not NASA observations. Even with real NASA frames, pixels are visual proxies: brightness or color is not measured temperature, aerosol concentration or current speed. Numerical datasets should replace pixel proxies wherever available.

Mapping table

Brightness → pitch (D minor pentatonic, D3–C6) · hue → timbre (Artistic mode) · horizontal position → stereo pan · vertical position → pitch variation · frame difference → filter brightness, urgency and tempo · sudden bright flash → percussion · pixel density → note density.

Visualizations: NASA Earth Information Center / Scientific Visualization Studio. This project is not endorsed by NASA.

Built for NASA Space Apps Challenge 2026 (The Earth Information Jukebox). Audio: Tone.js. All sound is generated live from the analysed frame; nothing is prerecorded.
